💡 How this simulation works

Budgets are consumed by everyone concurrently, day after day — not fully by the first users in the list. To model this realistically:

  1. Set a starting point: use the Global Usage Distribution below to give every user their day-to-day consumption, then click Set as Starting Point. This baseline is consumed by all users together.
  2. Adjust user by user: from that saved point, change individual users' consumption in the Simulation Results table. Every change is re-simulated for everyone: the shared cost center and enterprise pools are split concurrently across all users, while the overage (metered) budgets are drawn in the exact order you make the changes — so once a pool and its overage budget are both exhausted, every member competing for them is blocked.

🎛️ Global Budget Usage Simulation

Set what percentage of each budget is consumed to distribute usage equally among targeted users. Changes here push to individual users, but individual user edits are not reflected back here (one-way).
